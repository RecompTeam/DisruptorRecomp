## Linux

- On Linux the game can save. The AppImage kept the memory cards inside itself, where nothing can be written, so the game said GAME SAVES UNAVAILABLE.
- The memory cards are now in `~/.local/share/DisruptorRecompData/saves`, beside your other files.

## Launcher

- The launcher shows its last message in the banner, beside **Play**.
- **Troubleshooting** has a **Report a problem** button of its own.
- The portable ZIP no longer has Play Disruptor.cmd. Start the game with DisruptorLauncher.exe.

Version numbers drop the -alpha label from this release on.
